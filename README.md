Task 3: Case Studies with PDA and CFG

Project Description

This project demonstrates the use of Pushdown Automata (PDA) and Context-Free Grammar (CFG) to check different types of language structures.

Applications

1. Nested Tags

- Checks opening and closing HTML tags.
- Uses Stack (LIFO).
- Accepts correctly nested tags.
- Rejects mismatched tags.

2. Arithmetic Expressions

- Checks mathematical expressions.
- Uses CFG and LL(1) parsing.
- Supports addition, subtraction, multiplication and division.
- Checks brackets and operator order.

3. Dangling Else

- Checks programming-language structures.
- Uses Context-Free Grammar.
- Resolves ambiguity using matched and unmatched grammar.
- Follows the nearest unmatched if rule.

Technologies Used

- Programming Language: Python
- Concepts: PDA, CFG and LL(1) Parser
- Platform: VS Code / Python IDLE

How to Run

1. Install Python.
2. Create a file named "task3.py".
3. Copy the Python code into the file.
4. Run the program:

python task3.py

Conclusion

This project demonstrates how PDA and CFG are used to validate nested structures, arithmetic expressions and programming-language syntax. Stack memory helps to check nested tags, while grammar rules help to validate expressions and resolve ambiguity.
